# 腾讯云短信配置（验证码登录 / 注册）

## 1. 控制台准备

1. 打开 [腾讯云短信控制台](https://console.cloud.tencent.com/smsv2)
2. 开通短信服务，创建 **短信应用**，记下 **SDKAppID**
3. 国内短信 → **签名管理**：申请签名（与个体户/执照主体一致），审核通过
4. 国内短信 → **正文模板**：申请验证码模板，内容示例：  
   `您的验证码为{1}，5分钟内有效，请勿泄露。`  
   记下 **模板 ID**
5. 访问管理 → API 密钥：创建 `SecretId` / `SecretKey`（勿提交 Git）

## 2. 服务器 `.env`

在 `/opt/campus-secondhand/backend/.env` 追加（值换成你的）：

```env
SMS_PROVIDER=tencent
SMS_SECRET_ID=AKIDxxxx
SMS_SECRET_KEY=xxxx
SMS_SDK_APP_ID=1400xxxxxx
SMS_SIGN_NAME=你的签名内容
SMS_TEMPLATE_ID=1234567
SMS_REGION=ap-guangzhou
```

然后用 **ubuntu** 账号：

```bash
cd /opt/campus-secondhand/backend
pm2 restart campus-secondhand --update-env
```

未配齐时：开发/生产仍可用 `DEV_SMS_CODE`（生产需非默认或 `ALLOW_DEFAULT_SMS=1`），不会调用腾讯云。

## 3. 验收

1. PC / 小程序登录页 → **验证码登录** → 获取验证码 → 手机收到短信 → 登录成功  
2. 注册页获取验证码同样走真实短信  
3. **密码登录** 仍可用  

## 4. 相关接口

- `POST /api/v1/auth/send-code` — `{ phone, purpose?: 'login'|'register' }`
- `POST /api/v1/auth/login-by-code` — `{ phone, code }`
- `POST /api/v1/auth/login` — `{ phone, password }`（不变）
