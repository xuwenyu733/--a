# 小程序发货信息管理（实物电商）

支付成功后微信会要求录入发货信息，否则资金冻结、支付可能被再次限制。

## 自动录入（已接入代码）

正式微信支付成功后，后端会调用微信「发货信息录入」接口：

- 物流方式：`用户自提`（适合校园面交）
- 触发点：支付回调 `applyPaymentSuccess`
- 失败不影响支付成功。结果写入支付单 `shippingUploadStatus`，服务每分钟重试失败记录，达到次数上限后停止并保留错误信息。

部署后请 `pm2 restart campus-secondhand --update-env`。

## 手动补录（自动失败时）

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) → 码间校园市集  
2. **支付与交易** → **订单管理** → **发货信息录入**  
3. 找到待发货订单 → 发货  
4. 发货方式选 **用户自提** 或 **其他发货方式**（校园面交）  
5. 商品描述填商品名，确认提交  

建议每日看一眼「待发货 / 超时未发货」列表。

## 验收

1. 小程序正式版下一笔真实支付  
2. 数分钟后后台该单不再处于待发货，或日志出现 `发货录入成功`  
3. 买家微信可能收到发货相关通知
