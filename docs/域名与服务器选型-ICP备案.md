# 域名与服务器选型（ICP 备案）

面向本项目（Node + MongoDB + Nginx）首次上云：大陆机房部署、购买域名、办理 ICP 备案。个体工商户执照下来后按本文执行。

## 总原则

1. **域名、服务器买同一家**（阿里云或腾讯云），备案材料、解析、SSL 都更省事。
2. **域名持有人 = 营业执照主体全称**（个体户字号），须与备案主体一致，否则容易被退回。
3. **推荐顺序**：先买大陆服务器（≥ 3 个月）→ 注册并实名域名 → 执照下来后立刻提交备案。备案期间可用公网 IP 调试，不要急着挂域名正式上线。

## 一、服务器

### 配置对比

| 方案 | 配置 | 大约首年价 | 是否推荐 |
|------|------|------------|----------|
| **轻量 2 核 4G** | 约 4～5M 带宽，60～80G 盘 | **约 168～199 元/年**（新客活动） | **推荐**：本机跑 Node + Mongo + Nginx，够初期 |
| 轻量 2 核 2G | 更便宜 | **约 38～99 元/年** | 偏紧，Mongo 占内存后容易卡 |
| ECS 经济型 2 核 2G | 可扩容 | **约 99 元/年** | 偏长期运维，上手略复杂 |

> 价格以官网活动页实时为准（阿里云 / 腾讯云常有新客特惠）。

### 厂商怎么选

| 厂商 | 优点 | 说明 |
|------|------|------|
| **腾讯云轻量（Lighthouse）** | 备案流程顺、新客活动多、与微信小程序生态近 | **优先推荐** |
| **阿里云轻量 / ECS** | 文档多，与 OSS 衔接好 | 后期上图床更顺（见仓库 `OSS_SETUP.md`） |

### 地域与购买注意

- **地域**：用户在福建 / 厦门一带 → 选 **华南（广州）** 或 **华东（上海 / 杭州）**。
- **不要买**：香港、海外节点（免备案，但不能用国内域名正规挂站）。
- **时长**：包年包月，建议先买 **1 年**（满足备案「≥ 90 天」且剩余有效期通常够用）。
- **建议下单**：**大陆轻量应用服务器，2 核 4G，1 年**。

## 二、域名

### 后缀对比

| 后缀 | 首年大约 | 续费大约 | 建议 |
|------|----------|----------|------|
| **`.com`** | ~55～85 元 | ~90～95 元 | **首选**：正规、好记、对外好看 |
| **`.cn`** | ~29～38 元 | ~39～42 元 | 更便宜，纯国内也够用 |
| `.xyz` / `.icu` 等 | 很便宜 | 续费常暴涨 | **不建议**用于正式业务 |

### 买法

1. 在**同一云账号**内注册（阿里云万网 / 腾讯云域名）。
2. 立刻完成**实名认证**（个体户营业执照 + 经营者身份证）。
3. 备案时填报主体须与域名实名信息一致。

### 已定品牌与域名（2026-09）

| 项 | 选择 |
|----|------|
| **主选品牌** | **校园市集**（小程序/备案网站名优先用这个） |
| **备选品牌** | 同校转转 |
| **主选域名** | `xiaoyuanshiji.com`（备选 `xy-market.com`） |
| **备选域名** | `tongxiaozhuan.com`（若启用备选品牌） |

执照字号尽量与「校园市集」接近，备案与短信签名更顺。  
**执照下来前可先记名，不必急着付款**；购买时在**腾讯云同账号**查询并实名，主体 = 个体户全称。  
被占用可加短数字，**不要买高价二手域名**。

隐私政策 / 用户协议草稿见：[法律文本-隐私政策与用户协议.md](./法律文本-隐私政策与用户协议.md)。

## 四、备案与上线顺序

1. 个体户执照下来 → 云账号完成 **企业实名**（个体工商户）。
2. 购买 **大陆轻量 2 核 4G（建议 1 年）**。
3. 注册域名并完成实名（主体名 = 执照全称）。
4. 在云控制台提交 **ICP 备案**（网站类型按管局要求如实填写；涉及交易类服务以当地管局 / 云客服口径为准）。
5. 备案通过（常见 **7～20 个工作日**）→ 域名解析 → Nginx + HTTPS → 正式上线。

备案未通过前：用 **公网 IP** 按仓库 [`DEPLOY.md`](../DEPLOY.md)、[`LOCAL_STORAGE_DEPLOY.md`](../LOCAL_STORAGE_DEPLOY.md) 先把服务跑通。

### 备案常见前提（两家云大致相同）

- 服务器在中国内地，且为包年包月。
- 购买时长通常需 **≥ 90 天**，备案期间实例剩余有效期一般需 **≥ 30 天**。
- 域名在境内有资质注册商处、已实名、在有效期内。

## 五、一句话结论

| 项 | 选择 |
|----|------|
| 品牌 | **校园市集**（备选：同校转转） |
| 服务器 | 腾讯云 **大陆轻量**（已购广州实例可继续用） |
| 域名 | 同平台注册 **`xiaoyuanshiji.com`**（备选 `xy-market.com`），主体与个体户一致 |
| 避开 | 香港机、杂牌后缀、高价被抢注域名 |
