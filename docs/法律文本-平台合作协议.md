双方就乙方入驻「校园市集」平台（含微信小程序、网站等，下称「平台」）开展经营事宜，达成如下协议：

### 第一条 合作内容

1. 甲方提供平台技术服务，包括但不限于：店铺展示、商品发布、订单管理、消息沟通、相关审核与基础运营支持。  
2. 乙方在平台开设店铺或发布商品 / 服务，面向平台用户开展合法经营活动。  
3. 平台性质为**信息发布与交易撮合**；乙方与买方之间的买卖合同关系由乙方与买方自行建立并履行，甲方不作为买卖合同的卖方或买方（法律另有规定或页面另有明示的除外）。

### 第二条 入驻与审核

1. 乙方须按平台要求提交真实、合法、有效的入驻资料（如身份证件、营业执照、店铺信息等）。  
2. 甲方有权审核；资料不实、不全或经营项目违法违规的，甲方可拒绝入驻或要求限期整改。  
3. 乙方经营范围、商品及服务内容须符合国家法律法规及平台规则，不得销售违禁品或从事违法活动。

### 第三条 权利与义务

**甲方：**  
1. 保障平台基础功能正常运行（合理维护、升级除外）。  
2. 对违规内容、投诉举报进行核查处理。  
3. 有权制定并公示平台规则、收费标准（如有）及处罚措施。  

**乙方：**  
1. 保证所售商品 / 服务来源合法、描述真实，及时履约、售后。  
2. 妥善保管账号，对账号下全部行为负责。  
3. 不得利用平台从事欺诈、侵权、刷单、传销、洗钱等行为。  
4. 依法自行承担纳税、证照、售后及与消费者之间的法律责任。

### 第四条 费用

1. 入驻费、技术服务费、佣金等收费项目、标准及结算方式以平台公示或双方书面补充协议为准。  
2. 若暂不收费，双方确认：**本协议期内甲方对乙方【免收 / 按补充约定收取】平台服务费。**  
3. 支付通道、短信等第三方服务费用按其规则执行，与本条平台费用相互独立。

### 第五条 知识产权与数据

1. 平台软件、界面、商标、标识等知识产权归甲方或权利人所有。  
2. 乙方上传的商品图片、文案等，乙方保证有权使用；乙方授予甲方为提供本服务所必需的展示、存储、传输等非独占许可。  
3. 双方对合作过程中知悉的对方商业秘密、用户信息依法予以保密。

### 第六条 违规与终止

1. 乙方严重违规或违法的，甲方有权下架商品、限制功能、清退店铺并终止本协议，且不退还已收取的费用（如有）。  
2. 任意一方可提前【30】日书面通知解除本协议；乙方主动退出后，应妥善处理未完成订单。  
3. 协议终止后，已产生的订单责任、保密义务不因终止而免除。

### 第七条 免责与争议

1. 因不可抗力、政策调整、网络故障、第三方服务原因导致的服务中断或损失，双方在法律允许范围内协商处理。  
2. 因乙方商品、服务或履约引发的消费纠纷、行政处罚、索赔，由乙方自行承担；甲方已尽合理审核与协助义务的，不承担连带赔偿责任（法律另有规定除外）。  
3. 本协议适用中华人民共和国法律。争议协商不成的，提交甲方住所地有管辖权的人民法院诉讼解决。

### 第八条 其他

1. 本协议未尽事宜，可签订补充协议；补充协议与本协议具有同等效力。  
2. 本协议一式两份，甲乙双方各执一份，自双方签字（盖章）之日起生效。  
3. 乙方同时应遵守平台《用户服务协议》《隐私政策》及届时公示的商家规则。

### 第一条 合作方式

1. 甲方拥有「校园市集」平台（微信小程序、网站等）的运营权与技术管理权。  
2. 乙方经甲方同意，在约定区域 / 校区内使用平台开展推广、商家拓展、用户服务、本地运营等工作。  
3. 合作性质为【区域代理 / 联合运营 / 技术服务使用】（择一或注明），**不构成**甲方与乙方之间的劳动关系、合伙企业或分公司设立，除非双方另行依法设立经营主体。

### 第二条 授权范围

1. 授权区域：【具体学校 / 校区 / 城市】。  
2. 授权期限：自【　】年【　】月【　】日起至【　】年【　】月【　】日止；到期可书面续约。

4. 甲方保留对平台规则、功能、数据安全、全局账号与内容审核的最终管理权。

### 第三条 双方义务

**甲方：**  
1. 提供平台账号体系、基础功能及必要的操作说明。  
2. 对乙方提报的商家入驻、违规线索给予审核与处理支持。  
3. 保障平台核心服务的持续可用（计划内维护除外）。  

**乙方：**  
1. 合法合规开展推广与运营，不得虚假宣传、夸大授权范围。  
2. 拓展的商家、用户应引导其遵守平台协议与规则；对乙方自身过错造成的投诉、损失承担责任。  
3. 不得破解、倒卖平台数据，不得另建同名山寨应用误导用户。  
4. 按约定向甲方支付合作费用（如有），并保留必要经营台账。

1. 合作费用（技术服务费 / 分成 / 年费等）：【写明金额、比例、支付时间，或写「本协议期内暂不收费，后续以补充协议为准」】。

3. 乙方与商家、用户之间的费用关系，由乙方自行依法处理，与甲方无涉（页面明示由甲方收取的除外）。

### 第五条 品牌与宣传

1. 「校园市集」名称、Logo、界面设计等归甲方所有。  
2. 乙方对外宣传须使用甲方认可的表述，不得使人误认为乙方为平台唯一主体或总公司。  
3. 合作终止后，乙方应停止使用甲方品牌标识，并配合办理账号、资料交接。

### 第六条 违约、终止与争议

1. 乙方超出授权区域经营、严重损害平台声誉或违法违规的，甲方有权立即终止合作并追究责任。  
2. 任意一方提前【30】日书面通知可解除协议；因违约解除的，违约方赔偿由此给守约方造成的直接损失。  
3. 适用中华人民共和国法律；争议协商不成的，提交甲方住所地有管辖权的人民法院诉讼解决。

### 第七条 其他

1. 本协议一式两份，双方各执一份，签字（盖章）后生效。  
2. 未尽事宜以补充协议及平台公示规则为准。
