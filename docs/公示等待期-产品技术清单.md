## 一、本机环境占位（公示一通就能填）

`backend/.env` 建议保持：

```bash
PAYMENT_ENABLED=true
PAYMENT_MODE=sandbox
# 本地联调可先不填；局域网调试沙箱支付页时再填本机 IP
# PUBLIC_BASE_URL=http://192.168.x.x:3001
# PAYMENT_NOTIFY_BASE_URL=http://192.168.x.x:3001
```

域名 + HTTPS 备好后，改成（示例）：

```bash
PUBLIC_BASE_URL=https://api.你的域名.com
PAYMENT_NOTIFY_BASE_URL=https://api.你的域名.com
# 正式支付时再改：
# PAYMENT_MODE=live
# WECHAT_PAY_APP_ID=
# WECHAT_PAY_MCH_ID=
# WECHAT_PAY_API_KEY=
```

正式回调完整路径：

- `https://api.你的域名.com/api/v1/payments/notify/wechat`
- `https://api.你的域名.com/api/v1/payments/notify/alipay`

说明见 `backend/.env.example`。

## 二、沙箱支付联调（Web / 小程序）

前置：`npm run dev`，MongoDB 已启动；可用 seed 账号或两个已认证学生。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 买家：商品详情「立即下单」或购物车结算 | 订单创建，状态待确认 |
| 2 | 卖家：订单里确认订单 | 状态变为 `confirmed`（未确认不能在线付） |
| 3 | 买家：订单「去付款」→ 发起在线支付 | 生成支付单，`PAYMENT_MODE=sandbox` |
| 4 | 买家：点「模拟支付成功」 | 订单变为已在线支付 |
| 5 | （可选）Web 打开沙箱支付页 | 仅说明页，真正完成仍靠「模拟支付」 |

小程序编译：

```bash
cd uniapp && npm run build:mp-weixin
# 微信开发者工具打开 uniapp/unpackage/dist/dev/mp-weixin
```

## 四、微信公众平台（可不依赖公示先做的）

登录 [微信公众平台](https://mp.weixin.qq.com) → 你的小程序：

| # | 项 | 说明 |
|---|----|------|
| 1 | 基本信息 | 名称、简介、头像与「校园市集」一致 |
| 2 | 服务类目 | 按实际选（二手/电商交易等，以后台可选为准） |
| 3 | 用户隐私保护指引 | 收集手机号、位置（若用）、相册/相机（发图）等按功能勾选；文案对齐站内隐私政策 |
| 4 | 开发管理 | AppID 记入 `WECHAT_MINI_APP_ID`；开发阶段可用开发者工具 + 本机/局域网 API |
| 5 | 服务器域名 | 有 HTTPS 域名后再配 request / upload / socket；当前可用开发工具「不校验合法域名」联调 |
| 6 | 微信支付 / 微信认证 | **等公示可查 + 企业实名后再办** |
