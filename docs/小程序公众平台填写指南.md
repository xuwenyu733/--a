## 2. 服务类目

路径大致：**设置 → 基本设置 → 服务类目**

按后台实际可选勾选（不同主体开放类目不同），优先尝试：

1. **商家自营 / 电商平台 → 二手电商**（或「二手闲置」同类）  
2. 若无二手：选 **工具 → 信息查询** 或 **社交 → 社区/论坛**（以审核要求为准）  
3. 若有跑腿相关开放类目，可另加一条生活服务类  

类目选好后如需补充说明，可写：

```text
本校师生发布与浏览闲置商品，支持下单、聊天面交；另提供校园跑腿与简历相关工具服务。
```

## 3. 用户隐私保护指引

路径大致：**设置 → 服务内容声明 / 用户隐私保护指引**（名称以后台为准）

### 3.1 收集的信息（按你小程序真实能力勾选）

建议勾选（有对应功能再勾）：

| 用户信息类型 | 用途说明（可粘贴） |
|--------------|-------------------|
| 手机号 | 注册登录、账号安全与订单联系 |
| 位置信息（选填） | 同校面交地点、配送相关功能（用户主动填写或授权时） |
| 选中的照片或视频 | 发布商品、认证材料、聊天发图 |
| 摄像头 / 相册 | 同上 |
| 微信昵称头像（若用） | 展示个人信息与会话 |

### 3.2 存储期限 / 境外等

- 存储地点：中国境内  
- 存储期限：以实现目的所必需的最短时间，或按法律法规规定  
- 境外传输：无（若后台有选项选「不涉及」）

### 3.3 隐私政策文案（可粘贴到「自定义」或外链说明）

短版（后台字数紧时）：

```text
「校园市集」收集手机号、昵称、校区与认证材料、订单与聊天、设备日志等，用于注册登录、本校交易、审核风控与客服。我们不会出售个人信息。支付由持牌机构处理，我们仅接收支付结果。您可申请查询、更正、删除或注销账号。完整政策见小程序「我的 → 隐私政策」或 Web /privacy。
```

完整版：以仓库 `docs/法律文本-隐私政策与用户协议.md` 为准；站内页：小程序「我的 → 隐私政策」、Web `http://你的站点/privacy`。

> 有公网 HTTPS 域名后，可把「隐私政策外链」指到 `https://域名/privacy`。当前可用小程序内协议页，不必强行外链。

### 3.4 开发者联系方式

填你的手机或邮箱（与执照经营者一致更稳）。运营方全称：执照下来且公示可查后，把草稿里的「运营方」改成个体户全称。
